# Smart Academic Support System
An AI-powered platform designed to assist students and educators by leveraging machine learning and rule-based logic to provide academic insights.

## 🚀 Features
* **Intelligent Rule Engine:** Automated decision-making for academic queries.
* **Machine Learning Integration:** Predictive modeling for academic performance.
* **Interactive Web UI:** Built with Streamlit for a seamless user experience.
* **Data-Driven Insights:** Processing and analyzing academic datasets.

## 🛠️ Tech Stack
* **Language:** Python
* **Frontend:** Streamlit
* **Environment:** Dev Containers / Virtual Environments

## 📂 Project Structure
* `app.py`: Main Streamlit application entry point.
* `ml_model_updated.py`: Logic for machine learning models.
* `rule_engine_updated.py`: Core logic for academic rules and processing.
* `data/`: Dataset storage.
* `requirements.txt`: Python dependencies.
